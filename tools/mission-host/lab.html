01 / HELD-OUT FIELD TEST

Does the message change the mission?

Sixteen simulated agents work in four teams. Each team has a different sample to recover. A recovery needs three of its four agents to choose the correct sector. Every agent gets one private clue, correct about 65% of the time.

How agents learn

Each sender has a fixed three-symbol vocabulary. Each listener keeps its own count of which sector followed each sender’s symbol. After each of 48 training rounds the board reveals the true sector. A listener can interpret a symbol after at least three examples and a unique leading sector. It combines those peer votes with its own clue.

Memory is frozen for 32 fresh test rounds. The true sector is hidden until after the choices. Muting drops all peer packets, half loss drops packets by a seeded coin flip, and scrambling replaces each payload with a random symbol while preserving its sender and delivery. All three interventions apply only to simulated experimental traffic.
