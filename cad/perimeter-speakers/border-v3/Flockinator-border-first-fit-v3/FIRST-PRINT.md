# First print: coupon → one corner with two straight enclosures

This is an unsliced fit-test kit, not a ready-to-send printer job. Set **50% gyroid, five wall loops**, use your actual printer and filament presets, and review support placement in README.md.

## 1. Tiny snap test

Print one each:
- `Flockinator-snap-test-posts-v3.stl`
- `Flockinator-snap-bridge-v3.stl` (3.2 mm throat)
- `Flockinator-snap-bridge-loose-v3.stl` (3.6 mm throat)

Test both on the same paired posts by sliding sideways under the caps. Stop using a clip if it cracks or whitens. A static CAD clearance pass does not establish a working snap fit. Basic PLA is the proposed initial test material; actual material and orientation can change the result.

## 2. Check mounting before full enclosure prints

Print one straight rear cover and the spacer rings. The M3 pair should align at 90 mm centres and 7 mm inboard. Measure the recess seat depth/diameter. Use supported spacers as needed; do not bend tabs down into the recess. Check actual whiteboard clearance with hardware. This interface uses different mounting points from the already proven seam T/X connectors.

## 3. Corner and speaker sample

Once the interface fits, print:

| Part | Quantity |
| --- | ---: |
| straight-shell | 2 |
| straight-grille | 2 |
| speaker-retainer | 2 |
| straight-rear-cover | 2 total, including test cover |
| corner-shell | 1 |
| corner-rear-cover | 1 |
| chosen snap-bridge variant | 4 |

Two straights can first be joined in line to test that shiplap, then moved to adjoining edges of a single corner panel to test the corner. No duplicate handed parts are required.

Use white PLA for the shell, grille and corner to assess the continuous appearance. A second black grille can be printed later for a physical colour comparison. The retained speaker must be fully protected, with no pressure on diaphragms. Install fibre loosely behind the rigid housing, avoiding vents/moving parts. Test one enclosure with and without fibre for buzz/rattle and sound.

Pass conditions: mounts seat without bending; laps align without force; clips retain and release repeatedly without damage; screws engage without bottoming; all components and cable clear the whiteboard; factory lead reaches with slack or has a properly restrained extension; no diaphragm contact, rattle or excessive case flex. Record the clip variant, spacer stack, screw sizes, filament and any required corrections before the full border batch.
